Hızlı başlangıç

Sunucu çalışırken (npm start ya da baslat.bat) aşağıdaki adımlarla herhangi bir TikTok canlı yayınını dinlemeye başla. Tüm uç noktaların canlı listesi için GET /api adresine bak.

Domain: Panel localhost dışında bir alan adından da çalışır — bkz. Domain erişimi.

Kimlik doğrulama

Sunucu API_KEY ortam değişkeniyle başlatıldıysa tüm isteklerde anahtar gerekir. API_KEY tanımlı değilse sunucu açılışta rastgele bir anahtar üretir, data/apikey.json dosyasına kaydeder ve konsola yazar — panelde anahtar butonuyla gir.

HTTP başlığı

Tüm REST isteklerinde:

x-api-key: ANAHTAR
URL parametresi

SSE ve WebSocket bağlantılarında:

/api/streams/:user/sse?key=ANAHTAR
/ws?username=:user&key=ANAHTAR

Uç noktalar

Yayın yönetimi, istatistik ve olay uçları. :username TikTok kullanıcı adıdır.

Domain erişimi

Panel ve API yalnızca localhost'a bağlı değildir; sunucuyu bir alan adından ya da ağdaki başka bir makineden kullanmak için:

Not: Panel tüm istekleri göreli adreslerle yapar (/api, /ws) — domain'e taşındığında ek panel ayarı gerekmez. HTTPS arkasındaysa WebSocket otomatik wss olur. Dışarıya açarken API_KEY tanımlayın.

Olay türleri

WebSocket, SSE ve webhook üzerinden gelen olay nesneleri. Her olayda ts (ms) alanı bulunur; WS/SSE akışında ayrıca username eklenir.

WebSocket

Tek soketten tüm yayınları ya da belirli bir yayını dinle. Bağlantı açıkken {"types":["gift"]}, {"username":"…"} ve {"fields":[…]} mesajlarıyla filtreyi değiştirebilirsin.

Server-Sent Events

Tarayıcıdan kolay dinleme; event: adı olay türüdür (örn. gift), ilk olay hello yayın özetidir.

Webhook

WEBHOOK_URL tanımlıysa her olay, sunucu tarafından kendi adresine POST edilir. Gövde: { "username": "…", ...olay }. API anahtarı tanımlıysa x-api-key başlığı da gönderilir.

POST /senin/webhook/adresin
x-api-key: ANAHTAR            (API_KEY tanımlıysa)

{ "username": "virexhub1", "type": "gift", "ts": 1730000000000,
  "user": { "uniqueId": "ayse" }, "giftName": "Rose",
  "repeatCount": 5, "diamonds": 5, "countable": true }

Tüm ayarlar ortam değişkenleriyle yapılır; hiçbiri zorunlu değildir.

Yayın ekle

TikTok kullanıcı adı ya da yayın linki (örn. virexhub1 ya da https://www.tiktok.com/@virexhub1). Yayıncı canlı değilse canlı olunca otomatik bağlanılır.

Elmas hedefi

Hedefe ulaşıldığında Discord/Telegram bildirimi gider (tanımlıysa), panelde ses çalar ve OBS overlay çubuğu dolar. Hedef, mevcut toplamın üstünde olmalıdır.

CSV dışa aktar

@ arşivi — indirme bağlantıları (arşiv kapalıysa dosyalar boş gelir):

Olaylar (olaylar.csv) Günlük özet (ozet.csv) Gifterlar (gifterlar.csv)

API anahtarı

Sunucu açılışta bir API anahtarı üretir (konsolda yazar, data/apikey.json dosyasında saklanır) ya da .env'deki API_KEY'i kullanır. Anahtarı buraya gir — yalnızca bu tarayıcıda saklanır.
